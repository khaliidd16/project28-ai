## Python File Organizer

Built a Python automation tool that automatically organizes files into folders based on their file extensions.

### What I Learned

- Working with files and folders using `pathlib`
- Moving files using `shutil`
- Using loops to process multiple files
- Creating and calling functions
- Using function parameters
- Using dictionaries with keys and values
- Using `.get()` with a default value
- Checking files with `.is_file()`
- Creating folders with `.mkdir()`
- Refactoring code to reduce repeated `if / elif` statements

### File Organizer Features

- Images → `.jpg`, `.jpeg`, `.png`
- Documents → `.pdf`, `.txt`, `.docx`
- Music → `.mp3`, `.wav`
- Videos → `.mp4`, `.mov`
- Archives → `.zip`, `.rar`
- Unknown file types → `Other`
